# 簡單城建

[![Modrinth](https://img.shields.io/badge/Modrinth-1.20.1-00AF5C?logo=modrinth)](https://modrinth.com/mod/simple_city/)
[![License](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey)](https://creativecommons.org/licenses/by-nc-nd/4.0/)

一款普普通通、簡簡單單的地鐵設施擴充模組。建議搭配 [Minecraft Transit Railway](https://modrinth.com/mod/minecraft-transit-railway) 模組使用，以獲得更好的體驗。

---

## 功能特色

### 建築方塊
- **全色羊毛方塊**（半磚、樓梯、直向半磚）
- **全色混凝土方塊**（半磚、樓梯、直向半磚）
- *移植自 Minecraft 26.3*

### 地鐵設施
- 車站標示（低 / 高）
- 滅火器及滅火器箱
- 低月台屏蔽門欄杆
- 列車發車鈴
- 梧州地鐵標誌
- 導盲磚

### 道路設施
- 停車擋桿（左 / 中 / 右 / 支架）
- 道路標誌
- 施工圍欄

---

## 系統需求

| 相依元件 | 版本 |
|----------|------|
| **Minecraft** | 1.20.1 |
| **Fabric Loader** | &gt;= 0.14.9 |
| **Fabric API** | * |
| **Java** | &gt;= 17 |

---

## 安裝方式

1. 安裝 [Fabric Loader](https://fabricmc.net/use/)
2. 將模組 `.jar` 檔案放入 `mods/` 資料夾
3. （選用）安裝 [MTR 模組](https://modrinth.com/mod/minecraft-transit-railway) 以獲得更好的體驗
